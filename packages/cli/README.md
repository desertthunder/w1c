# @w1c/cli

Command-line scaffolding and terminal docs for W1C web components.

## Install

```sh
npm install --save-dev @w1c/cli
```

pnpm, Yarn, npm, and Bun can install the published package.

## Usage

```sh
w1c docs
w1c docs components/button
w1c docs --list
```

The CLI ships a `w1c` binary backed by the built `dist/main.mjs` entrypoint.
