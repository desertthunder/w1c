# References

See [Inspiration](/docs/inspiration/) for how the project came together.

## Apps

<div class="resource-list">

- [Intrepid Ibex](https://tangled.org/desertthunder.dev/ibex)  
  A SvelteKit Ubuntu 8.10 / GNOME 2 reference app. We use it for desktop panels, tan
  window chrome, app metaphors, dense spacing, and drag/resize expectations.

- [Tempest](https://tangled.org/desertthunder.dev/tempest)  
  A Phoenix app with Windows 95-style server-rendered UI. We use it for raised and
  sunken borders, document/admin surfaces, forms, status cards, tables, flash messages,
  and static HTML constraints.

</div>

## Libraries

<div class="resource-list">

- [Bolt Design System](https://boltdesignsystem.com/)  
  A useful model for separating foundations, layout, elements, components, animation,
  and guidelines.

- [Web Awesome](https://webawesome.com/)  
  A reference for all-in imports, cherry-picked imports, theme CSS, optional native
  styles, optional utilities, CDN usage, SSR notes, and asset base-path documentation.

- [Nord Design System](https://nordhealth.design/components/)  
  A reference for component catalog structure: status, category, description, examples,
  API, accessibility notes, theming notes, tokens, icons, and templates.

- [Freshworks Crayons](https://crayons.freshworks.com/)  
  A reference for no-build usage, CSS variable customization, utilities, icons, i18n, and
  framework-neutral web components.

</div>

## Classic Mac

<div class="resource-list">

- [System.css documentation](https://sakofchit.github.io/system.css/)  
  A CSS library for Apple System OS-style interfaces.

- [System.css repository](https://github.com/sakofchit/system.css/)  
  The source and license checkpoint for System.css.

- [AjaxIronside](https://ajaxironside.github.io/)  
  A compact classic Mac-style interface reference with menu, link, and window examples.

- [Recreating Classic Macintosh System 7 in CSS](https://bbenchoff.github.io/pages/system7.html)  
  A practical writeup on building a System 7-style desktop in CSS and JavaScript.

</div>

## Color systems

<div class="resource-list">

- [Reasonable Colors](https://github.com/matthewhowell/reasonable-colors)  
  A reference for predictable named color scales that work well as CSS variables.

## Web 1.0 and Geocities

<div class="resource-list">

- [GeoCities](https://en.wikipedia.org/wiki/GeoCities), [Web 1.0](https://en.wikipedia.org/wiki/Web_2.0#Web_1.0),
  [web design history](https://en.wikipedia.org/wiki/Web_design), and [tableless web design](https://en.wikipedia.org/wiki/Tableless_web_design)

  Background for personal homepages, neighborhood metaphors, early layout constraints,
  and the shift away from table-based layout.

  Cultural references for personal sites, dead links, page badges, under-construction
  patterns, webrings, counters, and the modern indie-web revival.

</div>
