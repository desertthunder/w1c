# Status Bar

Use `w1c-statusbar` for window footer text, counts, and small panes.

```ts
import '@w1c/components/statusbar';
```

```html
<w1c-statusbar>
	<span>Ready</span>
	<span>3 objects</span>
</w1c-statusbar>
```

## Slots

- default status content

## Parts

- `chrome`
- `statusbar`
- `content`
