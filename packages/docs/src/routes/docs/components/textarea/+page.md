# Textarea

Use `w1c-textarea` for notes, comments, and larger text fields.

```ts
import '@w1c/components/textarea';
```

```html
<w1c-textarea name="notes" rows="5" placeholder="Incident notes"></w1c-textarea>
```

## API

- `name`
- `value`
- `placeholder`
- `rows`
- `disabled`
- `readonly`
- `required`
- `invalid`

## Events

- `input`
- `change`

## CSS Parts

- `control`
- `textarea`
