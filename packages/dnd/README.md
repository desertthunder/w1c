# @w1c/dnd

Dependency-free drag, resize, pointer session, and geometry primitives for W1C components.

## Install

```sh
npm install @w1c/dnd
```

pnpm, Yarn, npm, and Bun can install the published package.

## Usage

```ts
import { createDragSession, createResizeSession } from '@w1c/dnd';
```

The package is framework-neutral and ships built ESM plus type declarations.
